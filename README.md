관리자, 알림, 태그 관련 처리는 V2부터

## Back-End

1. 회원가입
    - 다음 항목들을 입력 받는다.
        - 성명
        - 생년월일
        - 직책
            - 겸직도 가능
        - 직위
        - 이메일
        - 관심 태그 설정
2. 로그인/로그아웃
    - JWT 이용하기
    - Redis를 이용하여 세션 관리하기
    - Springboot Security를 사용하기
3. 게시글
    - 게시글 분류
        - 공지사항
        - 문의
        - 정보 공유
        - 회의록
        - 자유
        - 취미
    - 게시글에는 제목, 태그, 본문이 들어가야 한다
        - 이미지, 문서, 영상 등이 첨부될 수 있다
        - 익명으로 할 지 선택할 수 있다
    - 게시글 등록 시, 해당 태그의 관심 태그를 설정한 사람에게 알림이 간다
    - 자신이 작성한 게시글은 수정이 가능하다
    - 게시글에는 책갈피를 걸 수 있다.
4. 검색창
    - 분류 선택 시, 게시글이 해당 분류만 노출되도록 설정
    - 검색 시, 분류/태그/제목/작성자로 검색
    - 페이징 처리하기
5. 마이페이지
    - 프로필 사진, 이메일, 관심 태그 수정 가능
    - 자신이 작성한 글 확인 가능

## Front-End

1. NavBar
    - 왼쪽 끝에는 로고
    - 오른쪽에는 알림, 설정(로그아웃을 포함)
2. SideBar(left)
    - 가장 상단부터 프로필 사진과 이름, 내가 쓴 글, 글쓰기
    - 이후에는 본인이 책갈피를 걸어둔 게시글 목록
